# cheersfitLAB Analytics

치얼쓰핏 랩(CheersfitLAB) 쇼핑몰 데이터 수집 및 분석 프로젝트.

## 범위
- 광고 성과 (Meta / Google / Naver / Naver GFA / Kakao / TikTok / Coupang)
- 매출 / 판매 채널 데이터
- CRM / 고객 데이터 (세그먼트, 코호트, LTV/CAC)
- 이벤트 / 퍼널 데이터
- 종합 대시보드

## 구조
```
data/raw/        원본 데이터
data/processed/  가공된 데이터
scripts/         수집·가공 스크립트
notebooks/       탐색적 분석
reports/         최종 산출물 (대시보드, 리포트)
```

자세한 작업 방식은 [CLAUDE.md](CLAUDE.md) 참고.
